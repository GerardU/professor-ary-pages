# ビジュアルルーティンの購入とサブスクリプション

Routines+は任意です。価格、税、トライアル対象、請求条件はアプリ内のApp Store購入画面が正式な情報です。

- **月額：** 初回トライアルなしの自動更新。
- **年額：** 自動更新。対象アカウントには2週間の無料トライアルが表示される場合があります。
- **買い切り：** 更新のない1回限りの購入。

Routines+は複数の子ども、追加のルーティンとステップ、全画像、全履歴、追加メディア、任意のクラウド同期、保護者共有、ウィジェット、プレミアム書き出しを提供します。無料版はアカウントや広告なしでオフライン動作を続けます。

対象判定はAppleが行います。サブスクリプションはApple設定で解約しない限り表示価格で更新されます。復元は同じAppleアカウントで**設定 → Routines+ → 購入を復元**を開きます。復元で再課金されることはありません。

アプリ、データ、クラウドアカウントの削除では解約されません。**iOS設定 → [名前] → サブスクリプション**で管理してください。期限切れ後も、端末内データと無料版の中核機能は無料枠内で利用できます。
