# 비주얼 루틴 데이터 또는 계정 삭제

로컬 데이터, 선택형 클라우드 계정, App Store 구독은 서로 별개입니다.

## 로컬 데이터만 삭제

**설정 → 개인정보 및 데이터 → 로컬 데이터 삭제**에서 어른 확인을 통과하고 범위를 검토한 뒤 확인하세요. 해당 기기의 데이터만 삭제되며 클라우드 사본, 구매, 구독은 남습니다.

## 클라우드 계정 삭제

로그인한 상태에서 **설정 → 계정 및 가족 → Routines 클라우드 계정 삭제**를 선택하세요. 필요한 항목을 먼저 내보내고 어른 확인 후 완료 메시지를 기다리세요. 가족 접근, 루틴, 일정, 기록, 미디어, 공유, 초대, 기기, Routines+ 캐시가 삭제됩니다. 같은 Apple ID를 다른 Professor Ary 제품에서 사용하면 공유 인증 행만 남을 수 있지만 비주얼 루틴 데이터나 접근 권한은 남지 않습니다.

Apple 구매 기록은 삭제되지 않으며 결제도 자동 취소되지 않습니다. **iOS 설정 → [이름] → 구독**에서 별도로 취소하세요.

앱을 열 수 없으면 아이 정보나 비공개 링크 없이 [professoraryapp@gmail.com](mailto:professoraryapp@gmail.com)에 “비주얼 루틴 클라우드 계정 삭제”라고 요청하세요.
