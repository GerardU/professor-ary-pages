# 删除视觉日程数据或账户

本地数据、可选云账户和App Store订阅彼此独立。

## 仅删除本地数据

打开**设置 → 隐私与数据 → 删除本地数据**，通过成人确认，查看范围并确认。只会删除该设备的数据；云副本、购买和订阅仍保留。

## 删除云账户

登录后选择**设置 → 账户与家庭 → 删除Routines云账户**。先导出需要保留的内容，通过成人确认并等待完成。家庭访问、日程、计划、记录、媒体、分享、邀请、设备和Routines+缓存都会删除。若同一Apple身份仍用于其他Professor Ary产品，可能只保留共享身份验证记录，但不会保留视觉日程的数据或访问权限。

Apple购买记录不会删除，付款也不会自动取消。请在**iOS设置 → [姓名] → 订阅**中另行取消。

若无法访问应用，请勿发送儿童资料或私人链接，并通过 [professoraryapp@gmail.com](mailto:professoraryapp@gmail.com) 提出“删除视觉日程云账户”。
